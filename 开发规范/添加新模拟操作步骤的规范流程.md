## 添加新模拟操作步骤的规范流程

### 📋 完整步骤清单

#### **步骤 1: 定义新的 Step 类型**
**文件**: `SimSteps.cs`

```csharp
public record YourNewStep(参数1 类型 参数1, 参数2 类型 参数2, ...) : SimStep;
```

**命名规范**:
- Step 类型以 `Step` 结尾
- 参数命名遵循 PascalCase
- 结果参数建议以 `Result` 开头（如 `ResultIsValid`, `ResultUnitId`）

---

#### **步骤 2: 添加模拟逻辑方法**
**文件**: `Simulator.cs` (在 `extension(IGameState state)` 内部)

```csharp
public void ApplyYourNewAction(参数1 类型 参数1, 参数2 类型 参数2, SimulationResult? result)
{
	// 1. 检查是否为 Waiting 层（只记录，不实际修改）
	if (result?.Layer == SimulationLayer.Waiting)
	{
		result.Steps.Add(new YourNewStep(参数1, 参数2, ...));
		return;
	}
	
	// 2. 执行实际的模拟逻辑
	// 修改游戏状态...
	
	// 3. 记录步骤
	result?.Steps.Add(new YourNewStep(参数1, 参数2, ...));
}
```

**关键点**:
- 必须先检查 `result?.Layer == SimulationLayer.Waiting`
- Waiting 层只记录步骤，不修改游戏状态
- Running 层才实际修改游戏状态

---

#### **步骤 3: 在 ApplyResult 中添加应用效果**
**文件**: `Simulator.cs` (在 `ApplyResult` 方法的 switch 中)

```csharp
case YourNewStep yourNewStep:
	ApplyYourNewAction(state, yourNewStep.参数1, yourNewStep.参数2, null);
	break;
```

**位置**: 在 `ApplyResult` 方法的 `foreach (var step in result.Steps)` 循环内的 switch 语句中

---

#### **步骤 4: 添加运行时逻辑**
**文件**: `GameView.cs` (在 `RunSimulation` 方法中)

**位置**: 在 `_runningSimulations` 的 foreach 循环内（实际执行部分）

```csharp
case YourNewStep yourNewStep:
	// 执行运行时动画或效果
	await YourViewMethod(yourNewStep.参数1, yourNewStep.参数2);
	break;
```

**关键点**:
- 使用 `await` 确保动画按顺序执行
- 调用相应的 View 方法执行视觉效果

---

#### **步骤 5: 添加绘制方法**
**文件**: `EventView.cs`

```csharp
public void YourNewEvent(bool isFocus, 参数1 类型 参数1, 参数2 类型 参数2)
{
	var node = DrawNodePool.Pop();
	_nodes.Add(node);
	node.DrawAction += (u, v) =>
	{
		YourNewEventDraw(u, v, isFocus, 参数1, 参数2);
	};
	node.QueueRedraw();
}

private void YourNewEventDraw(DrawNode drawNode, bool visible, bool isFocus, 
	参数1 类型 参数1, 参数2 类型 参数2)
{
	if (visible)
	{
		// 绘制逻辑
		// 根据 isFocus 决定绘制样式
		drawNode.DrawTextureOffset(...);
		// 或修改 UnitsView/TilesView 的状态
	}
	else
	{
		// 清除逻辑（撤销绘制）
	}
}
```

**关键点**:
- 公共方法 `YourNewEvent` 用于设置绘制
- 私有方法 `YourNewEventDraw` 执行实际绘制
- 必须处理 `visible` 参数（true=显示，false=清除）
- 使用 `isFocus` 区分关注操作和普通操作

---

#### **步骤 6: 在 GameView 中调用绘制**
**文件**: `GameView.cs` (在 `RunSimulation` 方法中)

**位置**: 在 `_prepareSimulations` 的 foreach 循环内（预览部分）

```csharp
case YourNewStep yourNewStep:
	view.YourNewEvent(isFocused, yourNewStep.参数1, yourNewStep.参数2);
	break;
```

**关键点**:
- 使用 `isFocused` 变量（来自 `simulation.Layer == SimulationLayer.Focused`）
- 调用 `EventView` 中定义的绘制方法

---

## 📝 完整示例（以现有代码为例）

以 `MoveUnitPathStep` 为例：

### 1. SimSteps.cs
```csharp
public record MoveUnitPathStep(Vector2I Coords, List<Vector2I> Path, 
	uint ResultUnitId, int ResultTargetIndex, bool ResultIsValid) : SimStep;
```

### 2. Simulator.cs - 模拟逻辑
```csharp
public void ApplyMoveUnitPath(Vector2I coords, List<Vector2I> path, SimulationResult? result)
{
	if (path.Count == 0) return;
	var unit = state.UnitMapState.GetUnit(coords + path[0]);
	if (unit is null)
	{
		result?.Steps.Add(new MoveUnitPathStep(coords, path, 0, 0, false));
		return;
	}
	// ... 模拟逻辑
	state.ApplyMoveUnit(coords + path[0], coords + path[targetIndex], null);
	result?.Steps.Add(new MoveUnitPathStep(coords, path, unit.Id, targetIndex, true));
}
```

### 3. Simulator.cs - ApplyResult
```csharp
case MoveUnitPathStep movePathStep:
	ApplyMoveUnitPath(state, movePathStep.Coords, movePathStep.Path, null);
	break;
```

### 4. GameView.cs - 运行时
```csharp
case MoveUnitPathStep movePathStep:
	UnitsView.CurrentUnitId = movePathStep.ResultUnitId;
	if (movePathStep.ResultIsValid) 
		await UnitsView.CurrentMovePathUnit(movePathStep.Coords, 
			movePathStep.Path, movePathStep.ResultTargetIndex);
	break;
```

### 5. EventView.cs - 绘制
```csharp
public void MoveUnitPath(bool isFocus, uint unitId, Vector2I coords, 
	List<Vector2I> path, int targetIndex)
{
	var node = DrawNodePool.Pop();
	_nodes.Add(node);
	var lastAim = UnitsView.CurrentUnitAimCoords;
	node.DrawAction += (u, v) =>
	{
		MoveUnitPathDraw(u, v, isFocus, unitId, coords, path, targetIndex, lastAim);
	};
	node.QueueRedraw();
}
```

### 6. GameView.cs - 调用绘制
```csharp
case MoveUnitPathStep movePathStep:
	view.MoveUnitPath(isFocused, movePathStep.ResultUnitId, 
		movePathStep.Coords, movePathStep.Path, movePathStep.ResultTargetIndex);
	break;
```

---

## ⚠️ 注意事项

1. **Waiting 层只记录，不修改**: 所有模拟方法必须先检查 `result?.Layer`
2. **参数一致性**: Step 的参数、模拟方法参数、绘制方法参数要保持一致
3. **异步执行**: 运行时逻辑使用 `await` 确保动画顺序
4. **资源管理**: 使用对象池（`DrawNodePool`）管理绘制节点
5. **状态清理**: 绘制方法必须处理 `visible = false` 的情况，清除临时状态

这个规范流程可以确保新添加的模拟操作与现有架构完美集成！
